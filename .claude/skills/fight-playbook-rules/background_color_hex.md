# Background Color Hex Values (locked Nov 18, 2026)

Use these exact values every time for the rotation in background_color_rotation.md.
They match the palette Tik Tok Clips already uses (fightplaybook/tiktok/originals/lib/motion.py BG_PALETTE), so every channel shares one set.

| Color      | Hex     | RGB             |
|------------|---------|-----------------|
| pale blue  | #D8EEFE | (216, 238, 254) |
| warm sand  | #ECD6B0 | (236, 214, 176) |
| sage green | #C4D6C4 | (196, 214, 196) |
| slate gray | #BEC6D0 | (190, 198, 208) |
| deep teal  | #30767C | (48, 118, 124)  |
| cream      | #F5ECD6 | (245, 236, 214) |

Never pink or lime. Flat solid fill only, no gradients or textures.
